# 按现象排障

先运行 `scripts/lint_flow.py`，再用任务回执定位第一条异常命令；不要从后续连锁症状开始猜。

| 症状 | 常见根因 | 处理 |
|---|---|---|
| 元素明明存在却找不到 | 全匹配正则不符、界面语言不同或元素露出不足 10% | 重新抓当前屏结构；修正正则或先滚动到可见 |
| 大片 `SKIPPED` | 条件未成立、变量为空或 `branch` 没有 else | 检查条件字段、变量定义和分支兜底 |
| 点到相邻元素 | 多个元素命中，默认优先可点击项 | 用 `index`、`childOf` 或空间关系收窄 |
| 循环持续运行 | 条件恒真；循环没有隐式次数或时长兜底 | 修正条件、更新计数器、增加可达 `break` 或取消任务 |
| 循环一轮也不执行 | 首次 `while` 求值为假 | 若必须先执行一次，将首轮动作移到循环外 |
| 内层循环能退出，外层仍运行 | `break` 只退出最近一层 `repeat` | 为外层设计独立条件、标志或 `break` |
| 信息流每次滑动都卡顿 | 默认等待界面稳定 | 给滑动设置 `waitToSettleTimeoutMs: 0` |
| 换设备后点击偏移 | 使用绝对像素 | 改用稳定选择器或百分比坐标 |
| 子流程未执行但任务成功 | 使用 `runFlow.file` | 改为内联 `commands` |
| 中间失败但任务成功 | 失败发生在嵌套块 | 在顶层增加成败断言 |
| `retry` 没有重试 | 普通命令失败不会抛出给 `retry` | 使用有界 `repeat`，成功时 `break` |
| 断言恒过 | `assertTrue` 使用对象形态或非空字面量 | 改为表达式字符串 |
| 任务中断且步骤无失败标记 | 顶层 `${}` 求值失败 | 先定义变量；复杂计算移入 `evalScript` |
| `Invalid regular expression` | 文案中的正则元字符未转义 | 转义或改用 `id` |
| 输入 `[object Object]` | 标量命令收到对象 | 改为标量参数 |
| 等待后断言立即失败 | 等待耗尽了元素查找窗口 | 使用 `extendedWaitUntil` 给明确超时 |
| `${n + 1}` 得到 `"51"` | `n` 是字符串 | 保留数值类型或使用 `Number(n)` |
| HTTP 抽取为空 | `jsonPath` 一直无值，重试耗尽后写入空串 | 对输出变量做顶层断言 |
| `2fa` 报 Base32 错误 | 传了 otpauth URL 或非法字符 | 只传 URL 中的 Base32 secret |
| 弹窗偶尔漏处理 | 只在主流程检查一次 | 配置 `exceptionHandlers` 并限制 `maxTriggerCount` |
